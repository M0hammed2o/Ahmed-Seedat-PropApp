1Proplyst Mobile — design system + three directions
Analysis · what the web app already says

Web: off-white canvas, white cards with 1px soft borders and ~20px radius, one blue for actions and icon tints (pale blue circular icon chips), large dark financial numerals with a grey caption beneath, geometric sans headings, green reserved for "collected / active", red for outstanding. Properties page is already image-first with the name overlaid on the photo. Mobile refs confirm the hierarchy the brief asks for: one dominant blue money card, 2×2 KPI grid, "Needs attention" list with restrained chips, 4-item bottom nav.

How the three directions differ
1a Ledger — the most literal translation of the web. Off-white canvas, bordered white cards, one blue money card, 2×2 KPI grid, wordmark in header. Lowest risk, fastest to build on both platforms.
1b Navy Deck — borrows the dark-navy logo variant. A deep navy header holds the greeting and money figure; content cards slide up over it. Login is dark. Property cards are full-bleed photos with text on the image, like the web properties grid. Feels more premium/fintech.
1c Sky — lightest and most typographic. Pale blue-tinted canvas, borderless cards that read as soft plates, the money figure set as a large headline rather than in a card, floating pill bottom navigation, horizontal property carousel above the list. Most "app-like", least like the web.
Assumptions

Currency ZAR "R 20,000" as on web. Google is the only third-party sign-in. Demo data uses your real property names and photos from the web screenshots. Each screen is tappable: filters, tabs, sign-in states, report-payment toggle. Both device frames run the same screen with a platform flag, so the layout is proven cross-platform.
